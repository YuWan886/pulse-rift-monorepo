# PULSE//RIFT — Procedural Film

A 96-second, 1440p60 introduction film for **PULSE//RIFT · 律动裂隙**.

Every frame and every note is generated by code:

- **Picture** — Three.js / WebGL: procedural arenas, particle wordmark, neon shaders, instanced bullet notation, the gyroscopic Maestro, bloom + grain + chromatic aberration.
- **Sound** — Web Audio synthesis: 120 BPM, 48 bars in F minor (lifted to G minor for the overdrive), kick/snare/hats, side-chained bass, supersaws, arps, choir, FM bell "shot notes", algorithmic reverb, ping-pong delay.
- **Edit** — the EDL is generated on the 120 BPM grid: 48 shots, cuts on beats, captions and transitions scheduled from the same timeline that drives the music.
- **Render** — 12 × 8-second segments, frame-by-frame screenshots streamed into ffmpeg, losslessly concatenated, then mixed with the mastered soundtrack.

## Gameplay showcase series

Four **real-gameplay** clips, cut like a AAA gameplay showcase: chapter cards, the real
HUD, lower-third captions, a cinematic grade (grain, vignette, lifted shadows), and
code-synthesized chapter stingers.

| File | Length | Content |
|---|---|---|
| `out/PULSE-RIFT_gameplay_01_CORE_LOOP_1920x1080_60.mp4` | 19.5 s | WAVE 08 — on-beat fire, combo, graze, phase dash, overdrive |
| `out/PULSE-RIFT_gameplay_02_SIGNAL_BUILD_1920x1080_60.mp4` | 23.7 s | the real upgrade screen, two picks, four music tracks, the build payoff |
| `out/PULSE-RIFT_gameplay_03_THREATS_1920x1080_60.mp4` | 23.1 s | WAVE 09 bestiary — elite brutes, prisms, snipers, 23 grazes, overdrive |
| `out/PULSE-RIFT_gameplay_04_THE_MAESTRO_1920x1080_60.mp4` | 36.8 s | WAVE 10 boss — phases I–III, bullet notation, FINAL CADENCE |

The original 35-second boss capture remains at `out/PULSE-RIFT_gameplay_1920x1080_60.mp4`.

Posters: `out/poster_core.png`, `out/poster_build.png`, `out/poster_threats.png`,
`out/poster_maestro.png`, `out/poster_gameplay.png` (all 1920×1080).

Everything is captured from the actual browser game. `capture/gp_scene.js` launches
headless Chrome, starts a chosen wave through `PR.game.debugStart`, injects a
deterministic demo bot (on-beat fire, graze-seeking dodges, beat dashes, overdrive),
and records the canvas at 60 fps with `VideoEncoder` (WebCodecs/AVC) plus the live Web
Audio mix through a `MediaStreamDestination`. Upgrade-screen takes additionally run a
CDP page screencast at ~55 fps, and a real Playwright mouse hovers and clicks the cards.
The canvas recorder pauses at `SC_PAUSE_AT` only once the screencast is delivering
frames, so the two tracks can be joined without a held frame.

Audio is aligned with a flash + 1 kHz marker (`capture/measure.js`), the CDP screencast
is assembled at 60 fps (`capture/build_page.js`), and the edit (`capture/edit_clip.js`)
trims on beat, grades, overlays captions, mixes synthesized chapter beds
(`capture/make_stingers.js`) and masters to −16.3 LUFS / −1.5 dBTP.

## Rebuild

Large media is not versioned in this repository. The raw takes
(`capture/*.mp4`, `capture/*.webm`, `capture/*.wav`) are regenerated by the capture
scripts below, and the finished films in `out/*.mp4` are distributed separately
(GitHub Releases). All other intermediates are disposable as well: `capture/edit/`
(segment/caption intermediates), `capture/frames_*/` (CDP screencast frames),
`out/segments_*` (film segments) and `out/film_noaudio.mp4`.

```bash
cd pulse-rift-promo
node capture/render_audio.js      # segmented Web Audio -> soundtrack_raw.wav
ffmpeg -y -i capture/soundtrack_raw.wav \
  -af "highpass=f=30,equalizer=f=90:t=q:w=0.8:g=-2.5,equalizer=f=300:t=q:w=1:g=-1.2,equalizer=f=1800:t=q:w=1:g=1.5,equalizer=f=4000:t=q:w=1:g=1.5,treble=g=2:f=7000,volume=21.3dB,alimiter=limit=0.76:attack=5:release=80:level=disabled" \
  -ar 48000 -ac 2 -c:a pcm_s24le out/soundtrack_final.wav
W=2560 H=1440 FPS=60 node capture/render_video.js
W=2560 H=1440 FPS=60 node capture/finish.js

# gameplay series
node capture/make_cards.js                    # chapter cards + caption PNGs (cards/)
node capture/make_stingers.js                 # card / end beds (audio_sfx/)
MODE=canvas NAME=take_core8 WAVE=8 UPGRADES=split:2,echo:1,homing:1,quick:1,overflow:1,amp:1,presto:1 \
  DUR=16 BOT=storm ACTIONS=capture/act_core8.json node capture/gp_scene.js
MODE=both NAME=take_build4 WAVE=6 UPGRADES=amp:2,quick:1,vitality:1 DUR=21 BOT=storm \
  SC_AT=2.75 SC_PAUSE_AT=2.95 SC_OFF=7.7 ACTIONS=capture/act_build.json CLICKS='[{"at":4.6,"index":1},{"at":6.8,"index":0}]' \
  node capture/gp_scene.js
node capture/build_page.js take_build4        # screencast frames -> 60 fps page video
MODE=canvas NAME=take_threat9 WAVE=9 UPGRADES=split:1,homing:1,quick:1,vitality:1,harvest:1 \
  DUR=20 BOT=graze ACTIONS=capture/act_threat9.json node capture/gp_scene.js
node capture/edit_clip.js core
node capture/edit_clip.js build
node capture/edit_clip.js threats

# boss chapter — re-cut from the WebCodecs boss capture
ffmpeg -i capture/gp_sync2_video.webm -vf fps=60 -c:v libx264 -preset medium -crf 10 -pix_fmt yuv420p -an capture/gp_boss_video.mp4
cp capture/gp_sync2_audio.webm capture/gp_boss_audio.webm
node capture/edit_clip.js boss
```

The boss episode is captured with `capture/gameplay_wc.js`:

```bash
PUMP=interval THROTTLE=60 GW=1920 GH=1080 MAX_SEC=48 NAME=gp_sync2 node capture/gameplay_wc.js
```

All timings derive from `render/timeline.js` (`BPM = 120`, 48 bars = 96 seconds).
