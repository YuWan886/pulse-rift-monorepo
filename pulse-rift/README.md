# PULSE//RIFT · 律动裂隙

> **EVERY SHOT IS A NOTE.**
> 在崩坏的声场里，把每一次心跳写成子弹。

![PULSE//RIFT 标题画面](media/preview-title.png)

![PULSE//RIFT 战斗画面](media/preview-gameplay.png)

**PULSE//RIFT** 是一款运行在浏览器中的 **节奏 × 肉鸽 × 双摇杆射击** 游戏。  
120 BPM。所有敌人、弹幕、Boss、强化与音乐都在同一张节拍网格上呼吸。  
每一次踩拍射击都会让音乐更完整——你越准，世界越响。

---

## 快速开始

1. 用 **Chrome / Edge 最新版** 打开 `index.html`（也可以双击 `play.bat`）。
2. 在标题界面点击 **开始潜入**。首次点击会解锁浏览器的 Web Audio。
3. 建议佩戴耳机，使用 **键盘 + 鼠标**，全屏游玩体验最佳。

也可以启动本地服务器：

```bash
cd pulse-rift
python -m http.server 8123
# 打开 http://127.0.0.1:8123
```

> 如果节奏视觉与声音略有错位，打开 **设置 → 音画偏移**，拖动滑杆直到准星圆环闭合的瞬间正好是鼓点。设置会自动保存在本地。

## 核心玩法

### 踩着节拍开火

准星外的圆环会在每个节拍收缩至中心。**圆环闭合的瞬间点击左键**，就是 PERFECT。

| 判定 | 窗口 | 效果 |
|---|---|---|
| **PERFECT** | ±90ms | ×2.0 伤害 · 连击 · 同步率 · 金色音符 |
| **GOOD** | ±170ms | ×1.25 伤害 · 连击 |
| **OFF-BEAT** | 其余 | ×0.5 伤害 · 清空连击 |

- **长按左键 / J** 会按八分音符自动射击，但只有手动踩点才能累积连击和同步率。
- 连击每层 +1% 伤害，最高 +100%。受到伤害或打出 OFF-BEAT 会清空连击。
- PERFECT 的枪声会取用当前和弦的音高——打得越准，旋律越完整。

### 同步率与 OVERDRIVE

PERFECT 射击、完美闪避和 **擦弹**（贴着敌弹飞行）都会积攒同步率。  
同步率满格后按 **E** 进入 OVERDRIVE：8 拍火力全开、伤害提升、音乐升压。  
**在节拍上启动**，持续时间从 8 拍延长到 12 拍。

### 踩拍闪避

按 **SPACE** 朝移动方向闪避（站定时朝准星方向）。  
在节拍上闪避会释放 **相位冲击波**：清除周围弹幕、伤害敌人、积攒同步率，并给予更长的无敌帧。护盾类强化还能让完美闪避获得护盾。

### 擦弹

贴近敌弹而不被击中会获得同步率与分数。危险本身就是资源。

## 肉鸽构筑 × 生成式配乐

每波战斗结束后，从三张强化卡中选择一张。可重掷一次。

- **26 种强化**，分为 **POWER / STREAM / GUARD / PHASE** 四类，多数可以叠加。
- 每一类强化都会给实时合成的配乐**叠加一条音轨**：
  - POWER → **DRIVE**（失真贝斯层）
  - STREAM → **ARP**（追加琶音层）
  - GUARD → **PAD**（高频铺底）
  - PHASE → **PERC**（打击乐细节）
- 第一次升级某一类别时，会提示「新音轨接入配乐」。
- 强化组合会直接改变弹道：分裂、穿透、追踪、折射、回声、暴击、低音冲击波、收割碎片……
- 稀有度：常规 / 优良 / 稀有 / 史诗。波次越深，越容易出现稀有强化。

## 敌人与 Boss

- **8 种常规敌人**：脉冲机、织律者、轨道核、切分狙击、重低音兽、分裂酶、棱镜塔、突刺者。
- 每 5 波出现一个多阶段 Boss：
  - **WAVE 05 · OSTINATO 固定音型**——环形弹幕、狙击、旋转扫射光束。
  - **WAVE 10 · THE MAESTRO 指挥家**——螺旋音符、节拍墙、卫星齐射、召唤与交叉激光。
- 通过第 10 波后进入 **ENDLESS 无尽回廊**：Boss 每 5 波再度出现，数值持续爬升。
- 所有敌弹、光束、拍墙与攻击节奏都锁定在 120 BPM 的节拍上，用眼睛听音乐同样可行。

## 操作

| 输入 | 功能 |
|---|---|
| `W A S D` / 方向键 | 移动 |
| 鼠标 | 瞄准 |
| 左键 / `J` | 节拍射击（按住 = 自动八分音符射击） |
| `SPACE` | 冲刺 / 节拍闪避 |
| `E` | 同步率满时启动 OVERDRIVE |
| `1` `2` `3` | 选择强化（升级界面） |
| `R` | 重掷强化（升级界面） / 游戏结束后重试 |
| `ESC` / `P` | 暂停 / 继续 |
| `M` | 静音 / 恢复 |

## 生存提示

- 完美闪避不会打断连击，而且能清弹、积攒同步——**闪避不是逃跑，是节拍动作**。
- 低血量时，暗流类强化会提高伤害；但别为了伤害把自己送进弹幕。
- 护盾可以挡一次伤害，但不会保护连击；受到伤害仍然会清空连击。
- 先选一两类强化滚雪球，比把点数分散到所有类别更容易撑到后期。
- 长按自动射击适合专注走位；想冲高分，手动踩点 + 保持连击是核心。
- 每波开始前会有短暂的同步倒计时；音乐不会等你。

## 技术说明

- **全部画面**由 Canvas 2D 程序化绘制：无图片素材、无精灵图、无粒子贴图。发光由预烘焙的径向渐变精灵实现。
- **全部音乐与音效**由 Web Audio 实时合成：四拍底鼓、侧链压缩的 Pad/Bass、8/16 分琶音、延迟与卷积混响，以及随和弦变化的射击音符。
- 音乐调度器使用前瞻调度（look-ahead scheduler）；判定使用 `AudioContext.currentTime` 减去输出延迟和用户校准偏移，视觉节拍与判定窗口同步。
- 程序化合成器音轨会根据连击、波次、Boss 阶段、OVERDRIVE 和所选强化动态改变层数、滤波与能量。
- 支持暂停（挂起 AudioContext，使节拍完全冻结）与页面隐藏自动暂停。
- 高 DPI 屏幕会限制渲染分辨率以稳定帧率；支持减少震动、关闭闪烁与扫描线。
- 最高分、最高波次与设置保存在 `localStorage`。
- 无第三方运行时依赖；字体本地打包（见「字体」）。

### 开发者调试

在 URL 后加 `?debug=1` 会显示 FPS、节拍、实体数与延迟信息。  
控制台可直接访问 `PR.game`，提供 `debugStart(wave)`、`debugAddUpgrade(id, n)`、`debugKillAll()`、`debugSetGod(true)` 等测试入口。
